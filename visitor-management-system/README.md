# Visitor Management System

A comprehensive web-based visitor management system for tracking and managing visitor registration, check-in/check-out processes, and maintaining visitor records.

## Features

### 📋 Visitor Registration
- Complete visitor information capture
- Required fields validation
- Purpose of visit categorization
- Host assignment
- Additional notes support

### 📊 Real-time Statistics
- Total visitors count
- Currently checked-in visitors
- Today's visitor count
- Live dashboard updates

### 📝 Visitor Records Management
- Complete visitor history
- Check-in/check-out tracking
- Status management (Checked In/Checked Out)
- Record deletion capability
- Responsive data table

### 💾 Data Persistence
- Local storage implementation
- Automatic data saving
- Session persistence
- No server required

## Technologies Used

- **HTML5** - Structure and semantic markup
- **CSS3** - Modern styling with gradients and animations
- **JavaScript** - Interactive functionality and data management
- **Local Storage** - Client-side data persistence

## Getting Started

1. **Clone or Download** the repository
2. **Open** `index.html` in your web browser
3. **Start registering** visitors immediately

## Usage

### Registering a Visitor
1. Navigate to the "Register Visitor" tab
2. Fill in the required information:
   - Full Name (required)
   - Phone Number (required)
   - Purpose of Visit (required)
   - Host Name (required)
3. Optionally add email, company, and notes
4. Click "Check In Visitor"

### Managing Records
1. Switch to the "Visitor Records" tab
2. View all visitor entries with their status
3. Check out visitors using the "Check Out" button
4. Delete records if needed

### Dashboard Statistics
- Monitor real-time visitor statistics
- Track daily visitor counts
- See currently checked-in visitors
