# Opus — Task Management System

A sophisticated, modern task management application with an elegant dark interface and comprehensive productivity features.

## Features

### 📋 Task Management
- Create, edit, and delete tasks
- Mark tasks as complete/incomplete
- Rich task details with notes
- Priority levels (High, Medium, Low)
- Due date tracking with smart notifications
- Category organization

### 🎯 Smart Views
- **All Tasks** - Complete overview
- **Today** - Tasks due today and overdue
- **Upcoming** - Future scheduled tasks
- **Completed** - Finished tasks archive
- **Category Views** - Filter by Work, Personal, Health, Learning

### 🔍 Advanced Filtering & Search
- Real-time search across titles and notes
- Priority-based filtering
- Multiple sorting options (Date, Priority, Title)
- Smart grouping by due dates

### 📊 Progress Tracking
- Visual progress bar
- Completion statistics
- Category-wise task counts
- Real-time updates

### 🎨 Modern UI/UX
- Elegant dark theme with purple accents
- Smooth animations and transitions
- Responsive design for all devices
- Intuitive keyboard shortcuts
- Toast notifications for actions

## Technologies Used

- **HTML5** - Semantic structure
- **CSS3** - Modern styling with custom properties
- **JavaScript** - Interactive functionality
- **Local Storage** - Client-side data persistence
- **Google Fonts** - Typography (Playfair Display, Epilogue)

## Getting Started

1. **Open** `index.html` in your web browser
2. **Start creating** tasks immediately
3. **Organize** with categories and priorities
4. **Track progress** with the built-in dashboard

## Usage

### Creating Tasks
1. Click "New Task" or use `Ctrl/Cmd + K`
2. Fill in task details:
   - Title (required)
   - Notes (optional)
   - Category (Work, Personal, Health, Learning)
   - Priority (High, Medium, Low)
   - Due date (optional)
3. Click "Save Task"

### Managing Tasks
- **Complete**: Click the checkbox next to any task
- **Edit**: Click the edit icon when hovering over a task
- **Delete**: Click the delete icon when hovering over a task
- **Search**: Use the search bar to find specific tasks
- **Filter**: Use priority pills to filter by importance

### Navigation
- **Sidebar Views**: Switch between different task views
- **Categories**: Filter tasks by category
- **Progress**: Monitor completion statistics

## Keyboard Shortcuts

- `Ctrl/Cmd + K` - Create new task
- `Escape` - Close modal/cancel action
