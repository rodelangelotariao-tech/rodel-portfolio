# Weather App

A modern, responsive weather application that provides real-time weather information with an intuitive and visually appealing interface.

## Features

### 🌤️ Current Weather
- Real-time weather conditions
- Temperature display
- Weather descriptions
- Location-based data
- Atmospheric conditions

### 📍 Location Services
- Automatic location detection
- Manual location search
- City-based weather lookup
- Geolocation integration

### 🎨 Modern Interface
- Clean, responsive design
- Weather-appropriate backgrounds
- Smooth animations
- Mobile-friendly layout
- Intuitive user experience

### 📊 Weather Details
- Temperature readings
- Weather conditions
- Humidity levels
- Wind speed and direction
- Atmospheric pressure
- Visibility information

## Technologies Used

- **HTML5** - Structure and semantic markup
- **CSS3** - Modern styling and responsive design
- **JavaScript** - Interactive functionality and API integration
- **Weather API** - Real-time weather data
- **Geolocation API** - Location services

## Getting Started

1. **Open** `index.html` in your web browser
2. **Allow location access** when prompted (optional)
3. **Search for cities** or use current location
4. **View real-time weather** information

## Usage

### Getting Weather Information
1. **Automatic Location**: Allow browser location access for local weather
2. **Manual Search**: Enter city name in the search bar
3. **View Details**: See comprehensive weather information
4. **Refresh**: Update data for current conditions

### Features Overview
- **Current Conditions**: Live weather status
- **Temperature**: Accurate temperature readings
- **Location**: City and country information
- **Weather Icons**: Visual weather representations
- **Responsive Design**: Works on all devices
